# `hscmap-server`

`hscmap-server` is a small HTTP/WebSocket server for running Stellar Globe
(`hscMap`) without JupyterLab. It serves the built React frontend and relays
messages between the browser viewer and the Python `hscmap` client library.

Use it when you want to control Stellar Globe from a normal Python process,
from a command line workflow, or from an environment where the JupyterLab
extension is not available.

## What it provides

- A command line program, `hscmap-server`, that binds to the requested host and
  port.
- Static serving for the built Stellar Globe frontend.
- WebSocket endpoints under `/comms` that relay state updates and commands
  between Python and the browser.
- Same-origin browser connections, so changing `--host` or `--port` does not
  require rebuilding the frontend.

## Setup

Install the Python dependencies and build the frontend once. `make build-frontend`
also builds the local Stellar Globe packages that the Vite app imports. The
generated `src/hscmapserver/static/dist/` directory is a build artifact and is
not tracked by git.

```bash
make setup
make build-frontend
```

## Run from the command line

```bash
uv run hscmap-server --host 127.0.0.1 --port 8000
```

Open `http://127.0.0.1:8000/` to view Stellar Globe directly. To control it
from Python, create a `Window` using the matching frontend and backend URLs:

```python
from hscmap import Window
from hscmap.comm.hscmapserver import HscmapServerCommOptions

w = Window(comm_options=HscmapServerCommOptions(
    frontend_url="http://127.0.0.1:8000",
    backend_url="ws://127.0.0.1:8000",
    open_browser=True,
))
```

If `open_browser=False`, the Python client prints a URL containing the generated
communication ID. Open that URL in a browser to connect the viewer.

## Custom static directory

By default, the server uses the frontend build generated by `make build-frontend`. During development you
can serve another build directory:

```bash
uv run hscmap-server --port 9000 --static-dir ./static/dist
```

The directory must contain `index.html` and the Vite `assets/` directory.

## Development commands

```bash
make dev            # run the server on 127.0.0.1:8000
make test           # run Python tests
make build-frontend # build the React frontend into the Python package
```
