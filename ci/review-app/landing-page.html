Stellar Globe Review App

この review app では、MR ごとの成果物を個別に確認できます。各プロダクトは以下のリンクから開いてください。

  • Standalone App

    app の standalone build です。Web アプリ本体の動作を確認できます。

    ./standalone/

  • JupyterLite

    python-integration/jupyterlite の成果物です。ブラウザ上での JupyterLite 連携を確認できます。

    ./jupyterlite/

  • JupyterLite E2E Report

    Playwright の HTML report です。成功時の screenshot を含めて JupyterLite E2E の結果を確認できます。

    ./jupyterlite-e2e/
